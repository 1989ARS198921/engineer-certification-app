# Engineer Certification App

Приложение для подготовки к категории инженера серийного сопровождения.

## 🚀 Функционал

- 🔐 Регистрация и вход
- 📚 9 разделов с теорией
- 📝 Тестирование с подсветкой ответов
- 📊 Визуализация прогресса (диаграммы)
- 👑 Админ-панель (пароль: admin123)
- 🌙 Тёмная тема
- 🏆 Рейтинг пользователей

## 🛠️ Технологии

- Node.js + Express
- HTML + CSS + JavaScript
- Chart.js для диаграмм
- JWT для аутентификации
